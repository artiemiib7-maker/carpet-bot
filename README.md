# Telegram-бот «Стирка ковров»

🎬 **Демо работы бота:** https://youtu.be/8JTpKb8Hfhs

Бот принимает заказы на стирку ковров, считает стоимость, показывает клиенту статус
и в день доставки напоминает принять заказ. База заказов — Google Sheets.

## 1. Создание бота в @BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Придумайте название бота (например, «Стирка ковров — Чайковск»).
4. Придумайте username — должен заканчиваться на `bot` (например, `carpet_wash_bot`).
5. BotFather пришлёт **токен** вида `123456789:AAEhBOweik6ad...` — сохраните его, это BOT_TOKEN.

## 2. Сервисный аккаунт Google Cloud

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/) и создайте проект
   (или выберите существующий).
2. В меню «APIs & Services → Library» найдите **Google Sheets API** и нажмите **Enable**.
3. Перейдите в «APIs & Services → Credentials» → «Create Credentials» → **Service Account**.
4. Задайте имя аккаунта (например, `carpet-bot`), нажмите Create / Done.
5. Откройте созданный сервисный аккаунт → вкладка **Keys** → «Add Key» → «Create new key»
   → формат **JSON** → скачается файл ключей.
6. Переименуйте скачанный файл в `credentials.json` и положите его в папку бота
   (`carpet-bot/credentials.json`).

## 3. Таблица Google Sheets

1. Создайте новую таблицу на [Google Sheets](https://sheets.new).
2. Скопируйте **SPREADSHEET_ID** из URL таблицы — это длинный код между `/d/` и `/edit`:
   `https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit`
3. Откройте `credentials.json` и найдите поле `client_email`
   (вида `carpet-bot@project.iam.gserviceaccount.com`).
4. В таблице нажмите «Настройки доступа» (Share) и выдайте этому email права
   **Редактор** — иначе бот не сможет писать в таблицу.
5. Лист «Заказы» и заголовки колонок бот создаст сам при первом запуске.

## 4. Установка (Windows)

```bat
cd carpet-bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Откройте `.env` в блокноте и впишите значения:

```
BOT_TOKEN=токен_от_BotFather
SPREADSHEET_ID=код_таблицы_из_URL
```

## 5. Запуск

```bat
.venv\Scripts\activate
python bot.py
```

Остановить бота: `Ctrl+C`. Пока окно с ботом открыто — бот работает.

Бот запустится и без `credentials.json` (увидите предупреждение в логе): заказы будут
приниматься и писаться в лог, но в таблицу не попадут. Это удобно для проверки.

## 6. Уведомления клиентам при смене статуса (макрос таблицы)

Бонус к боту: таблица сама шлёт клиенту сообщение в Telegram, когда сотрудник меняет
статус заказа. Сообщение приходит **мгновенно** (бот Python в этот момент может быть
выключен — скрипт работает на серверах Google).

1. Откройте таблицу → меню **Расширения → Apps Script**.
2. Удалите всё в редакторе и вставьте содержимое файла `telegram_notifications.gs`
   из папки бота.
3. **Настройки проекта → Свойства скрипта → «Добавить свойство»**: имя `BOT_TOKEN`,
   значение — токен бота от @BotFather (тот же, что в `.env`).
4. Слева откройте **Триггеры** (иконка часов) → «Добавить триггер»: функция `onEdit`,
   тип события «Из таблицы» → «При изменении» (При редактировании).
5. Сохраните. При первой смене статуса Google попросит авторизацию — разрешите.

Результат: правка статуса на `принят` → клиенту сразу «Ваш ковёр принят в работу» и т.д.
При статусе `упакован` клиенту приходит сообщение **с кнопками выбора даты доставки** —
он нажимает дату прямо в Telegram, дальше выбирает время (9:00–18:00, шаг 10 минут),
выбор записывается в таблицу. Тексты сообщений и список статусов настраиваются
в начале скрипта (`STATUS_MESSAGES`).

Важно: кнопки обрабатывает Python-бот — он должен быть запущен, когда клиент
по ним нажимает (само сообщение со кнопками уходит от скрипта и без него).
Скрипт ставит флаг «готов_уведомлён», поэтому почасовой бот не продублирует сообщение.

## 7. Как сотруднику менять этапы заказа

Всё управление — через таблицу Google Sheets, лист **«Заказы»**:

- **статус** — вручную меняйте на один из этапов: `отгружен` → `принят` → `упакован` →
  `доставлен`. Бот показывает этот этап клиенту в «Мои заказы». При смене статуса клиенту
  автоматически приходит сообщение (макрос из раздела 6). Когда поставите `доставлен`,
  бот перестанет присылать уведомления по заказу.
- **уведомлён** — `да`/`нет`, заполняет бот. Если сменить вручную на `нет`, уведомление
  в день доставки придёт ещё раз.
- **доплата_перенос** — сумма доплат за переносы даты (+100 ₽ за каждый перенос),
  заполняет бот.
- **дата_доставки** — можно править вручную в формате `ГГГГ-ММ-ДД` (например,
  `2025-07-10`).

Ничего больше в таблице менять не нужно: номера заказов, суммы и даты бот заполняет сам.

## Структура проекта

```
carpet-bot/
  bot.py            # точка входа: dispatcher, роутеры, фоновая задача уведомлений
  config.py         # тарифы, маршруты, допуслуги, телефоны водителей, тексты
  states.py         # FSM-состояния (OrderForm, RescheduleForm)
  keyboards.py      # inline/reply клавиатуры
  sheets.py         # работа с Google Sheets
  notifier.py       # фоновые уведомления в день доставки (раз в час)
  handlers/
    start.py        # /start, главное меню
    order.py        # FSM оформления заказа + расчёт цены
    status.py       # «Мои заказы»
    delivery.py     # реакции на уведомление: готов / перенос / звонок водителю
  requirements.txt
  .env.example
```

Телефоны водителей по маршрутам задаются в `config.py` (словарь `DRIVER_PHONES`) —
сейчас там заглушки `+7 XXX XXX-XX-XX`, замените на реальные номера.
